# Promux

> Fast project switching and tmux workspace management for terminal developers.

Promux is a lightweight CLI tool that helps developers quickly switch between projects by automatically creating and managing tmux workspaces.

Currently focused on:

- Linux
- tmux
- terminal-first workflows

---

# Current State

Promux is currently in early development (`v0.1.0`).

The initial goal is to support:

- project root configuration
- project discovery
- tmux session creation
- automatic editor window setup
- session reattachment

---

# Planned Workflow

Run:

```bash
promux
```
